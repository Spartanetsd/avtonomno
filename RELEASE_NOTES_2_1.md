# Автономно 2.1.0 — нотатки до релізу

## Виправлено

- Відсутні в резерві ковдри, відро, пакети не вважаються наявними за замовчуванням. Невідоме обладнання не використовується як підтверджений ресурс.
- Зарядна станція сама по собі не означає наявність нагрівача. Для нагріву 230 В від станції потрібні підтверджені нагрівач і AC-вихід, а також потужність нагрівача не більша за тривалу потужність виходу станції.
- Рішення про гарячу їжу та окріп від електроприладів не пропонуються як здійсненні тільки через наявність зарядної станції. Для термоса потрібен підтверджений окріп або реальне джерело нагріву.
- Пальник потребує наявності картриджа і підтвердженої безпеки виходу надвір. Рекомендація не заохочує користування ним у квартирі.
- «Мій стан сьогодні»: окреме питання про безпеку виходу надвір. Невідомо — консервативна заборона рекомендацій, які потребують виходу.
- Режим укриття не видає власний сигнал відбою: користувач підтверджує, що перевірив офіційні джерела. Відлік часу — це час перебування, не гарантія безпеки.
- За підозри на чадний газ першою дією зазначено негайну евакуацію на свіже повітря, а не відкривання вікон або вимкнення приладів.
- Повний JSON-експорт охоплює запаси, профіль, стан, обране, нотатки, валізку, підготовку, тему, калькулятори й статистику укриттів. Активний режим укриття не переноситься через імпорт.
- Кеш основного застосунку та 38 зображень позначені окремо. Додано ручне збереження ілюстрацій.
- Робочий процес GitHub Actions у правильному каталозі `.github/workflows/` із `npm ci`, `npm test` та `npm run check`.
- Додано `.gitignore`, `package-lock.json`, сім регресійних тестів і допоміжний `browser_smoke.py`.

## Обмеження

Застосунок не отримує офіційний статус тривоги, не оцінює реальну небезпеку виходу, не перевіряє паспорт обладнання автоматично. Наявність електроприладу та відповідність його потужності не гарантують достатню кількість енергії для конкретного об'єму води. Рекомендації з медичної, пожежної та цивільної безпеки повинні пройти зовнішню перевірку компетентними фахівцями перед масовим використанням. На реальному iPhone та GitHub Pages цей реліз тут не перевірений.

## Перевірки

- `npm test` — 68 тестів, включно із сімома регресійними тестами версії 2.1.
- `npm run check` — статична перевірка TypeScript для JS-модулів.
- `node --check` — синтаксис JS-модулів.
- `browser_smoke.py` — надано відтворюваний smoke-тест на Chromium/Playwright, але у середовищі збірки всі спроби браузерної навігації заблоковано адміністратором (`ERR_BLOCKED_BY_ADMINISTRATOR`).

**Порядок оновлення:** на старій адресі сайту зробіть експорт JSON, потім оновіть файли репозиторію. Після нового завантаження застосунок мігрує localStorage до схеми 3. На іншій адресі — імпортуйте резервну копію JSON.
